この資料について
スタッフのテスト実走用に、お店ごとに必要なアプリとURLをまとめました。ご自分のお店のページだけを見ていただければ大丈夫です。URLはタップすると全選択できます。

01はじめに ・ ホーム画面に追加Getting Started

毎回URLを打つ必要はありません。最初に一度だけ、ホーム画面に追加しておくと、アプリのように開けます。

1
ご自分のお店のURLを開く
iPhone / iPad は Safari、Android は Chrome で開いてください。
2
ホーム画面に追加する
Safari：共有ボタン → 「ホーム画面に追加」／Chrome：右上の︙ → 「ホーム画面に追加」
3
次からはアイコンをタップ
画面が古いまま変わらないときは、下に引っぱって再読み込みしてください。

04テスト中に見ていただきたいことWhat to Test

今回から変わったところ
  • お子様の年齢は「生まれた年・月」で入力します。選ぶとその場で「◯歳◯ヶ月」と表示されます
  • 1歳6ヶ月までのお子様は、0歳の枠と1歳の枠を両方使います（1歳7ヶ月からは1歳の枠だけ）
  • サロンで予約を入れると、保育園のボードに通知が届きます（音が鳴ります）
  • 受け入れ制限中の時間帯に予約すると、確認画面が出ます
気づいたことの伝え方
次の4つがあると、すぐ直せます。 ①どの画面か ②どこで ③何をしようとして ④どうなってほしかったか
例：「サロン予約画面の、生まれ月を選ぶところで、1歳6ヶ月の子を予約したかったが、満員と出て入れられなかった」

05お願い ・ 注意Notes

⚠ 大切なこと
  • この資料のURLをそのまま使ってください。他の方から回ってきたURLは、別の園のものかもしれません
  • 予約や通知は他の端末にもすぐ反映されます。テストであっても、実際のお客様の予約と混ざらないようご注意ください
  • 受付アプリ（TimelySchool）の「全データ削除」「サンプルデータを投入」は押さないでください
  • 受付アプリのお客様情報・来園記録・お会計は、その端末だけに保存されます。終業時のバックアップをお願いします（取扱説明書 SECTION 11）
